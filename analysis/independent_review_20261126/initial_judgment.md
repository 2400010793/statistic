# 独立初始判断（2026-11-26；在阅读历史脚本、结论和 scores 前保存）

依据仅为 inspect_data.py 与 data_inspection.json。三个阶段分别有 16,787 / 17,057 / 24,979 个细胞、18 / 21 / 23 种原始标签；只有 celltype，没有可用于生物学重复的胚胎/批次字段。基因顺序与 T1 val 的 32,285 基因一致。X 为 CSC，浮点非整数；随机 1,000 个细胞 expm1(X) 的行和均约 10,000，符合 log1p(CP10K)。存储有显式零，所以 nnz 密度不等于真实检出率。

1. 可以估计已有群的表达均值、比例及其早期变化，较大群的共享表达变化可能具有短程延续性。不能仅凭两个阶段识别加速度、谱系对应、新群产生、细胞增殖与取样比例的区别，也不能分离阶段与批次。两早期阶段仅 11 个标签直接共有，不能把新标签直接理解为新谱系。早期总体均值 RMSE 0.03110，小于各共有群均值变化（约 0.0405–0.0872）；群体组成变化可能抵消群内变化。最大变化中出现 Xist、核糖体相关基因，提醒需要警惕性别、技术或组成混杂，不能据此断言其成因。

2. 最怀疑以 E10.5 的总体均值或按真实细胞数加权的群内均值评价时，共享的表达尺度/收缩修正会被解释成细胞类型特异的发育规律。源细胞抽样、类型合并和目标阶段权重也可能带来改善。E10.5 的 log 空间行和中位数更低（3,571 vs 3,923），但 CP10K 总量相同，简单降幅就可能让部分均值指标变好，不能由此推断学到了正确生物轨迹。

3. 优先假设：群内均值改善的主要部分可能来自各群共享的修正，而不是把正确修正分配给正确群。最想做相同源细胞、相同修正规模下的群特异性消融/错配对照，同时看总体方向。若正确群对应在等群权重和目标频率权重下均稳定优于共享或错配对照，且方向代价可解释，我将放弃“主要由非特异修正解释”的假设；若消融无损或更好，则不能把均值收益作为学到群特异动力学的证据。此时只提出假设，具体公平消融将在读实现后固定；目标阶段分析明确是回顾性。
