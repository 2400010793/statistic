# T1 组内交接 · 2026-11-24

我们用早期小鼠胚胎单细胞 RNA 表达快照，预测后续阶段的细胞表达分布。当前主模型为 R40，已记录的最高 T1 P2 验证分为 **51.0397**。最近的群比例候选为 **50.6040**。这份记录覆盖 E10.5 验证和外部 E9.25 回测；最终测试目标为 E12.5。

## 从数据到结论

1. **数据探索。** 官方 E8.5、E9.5 分别有 16,787、17,057 个细胞，共用 32,285 个基因。我们检查了矩阵非负性、稀疏性、基因顺序及细胞类型组成。每个阶段是一次横截面采样，模型评价对象是整群分布。
2. **从基线到 R40。** 自己实现的最近阶段重采样基线在 P2 得到 46.7599。我们比较了线性均值修正、低维外推、最优传输和神经模型。神经传输加表达解码达到 50.7919，约束 50 个投影坐标的版本达到 50.7971。R40 在该版本上沿训练数据估计的一个群体变化方向修正剩余偏差的一半，保留其余 49 个坐标、表达正值位置及每细胞归一化总量。
3. **外推诊断。** 用 GSE126128 的 E7.75、E8.25 拟合，再在原研究与 GSE205950 的独立来源样本 GSM6235983 上分别评价 E9.25。拆开组内与群体修正后，原研究主评估中，单独开启群体修正使 MMD² 上升约 42.4%。跨研究验证也有测序和群体组成差异；同队列抽样只反映细胞抽样波动。外部队列已反复用于开发。
4. **群比例实验。** 固定细胞表达，仅改变 12 个群的权重，比较沿用最近阶段比例、晚期相似度加权和两步状态转移。沿用比例在两个队列的群占比误差和 MMD² 上均最好。把权重落实为 2,000 行后，再与等量的原始 R40 对照，本地无偏 MMD² 分别从 0.03612 降至 0.03054、从 0.12505 降至 0.11758。原研究的差异基因恢复略降，外部队列该指标略升。
5. **官方反馈。** 对 E10.5，沿用 E9.5 比例使四项技能分都下降。该版本保留为负结果。两种模型在两个目标阶段上的对照说明，E9.25 本地分布距离的改善不足以预测官方榜单收益。

## 组员如何接手

- **写报告或核对数字**：在仓库根目录运行下面的第一条命令，仅使用 Python 标准库。[历次官方验证成绩](p2_scores.csv) 收录 19 份已评分回执的汇总；[配对回测](e925_paired_metrics.json) 保留逐批指标；[群比例三种方法的对照](e925_composition.txt) 采用含对角项的 MMD²。后者与配对回测的无偏 MMD² 属于不同估计量。
- **复核模型**：组内文件包解压到独立工作目录，包含两期 T1 训练数据、R36 所需中间产物、R40 和群比例候选预测。进入解压目录执行第二条命令，再对照第三、四条命令。工具链需要 Python 3.11+ 及 NumPy、SciPy、pandas、anndata、scikit-learn、joblib、threadpoolctl。R40 入口重建最后的校正步骤，运行时会写入工作目录的 R40 结果子目录，建议使用文件包的工作副本。生成群比例候选可直接使用包内已评分的原始 R40 文件，其哈希由脚本校验。
